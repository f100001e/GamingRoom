# GamingRoom

The Gaming Room client needed a web-based design for their Android game "Draw It or Lose It" to support multiple teams and game sessions. I did well at identifying security vulnerabilities like authentication and session management. The design document helped me think through architecture before coding, which made implementation easier. I would revise the scalability analysis to include more specific load-testing strategies. Interpreting user needs meant designing an intuitive, responsive, and secure interface, because users abandon software that is slow or confusing. My approach used modular architecture, and I would use similar strategies like UML modeling, threat modeling, and heap observation tools like JVisualVM and Eclipse MAT for memory analysis in the future.
